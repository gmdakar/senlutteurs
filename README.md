# Senlutteurs

Drupal project providing statistics and profiles on Senegalese wrestlers.
Projet Drupal destiné à fournir des statistiques et des profils sur les lutteurs sénégalais. Enjoy!


## Local setup

1. Install DDEV
2. Run `ddev composer install && ddev start`
3. Visit the site at http://senelutte.ddev.site
